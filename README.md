# How Does Compute Scale with World State Complexity in LLM-Generated Visual Novel Schemas?

## Abstract

Visual novels are often combined with text and images. Each components in a visual novel serves as parts in a multimodal reasoning. Connecting text and images could introduce concerns in inference. In the case of visual novels, balancing the entire "world" during inference takes up a lot of resources, especially with how rich in storytelling and narration visual novels are.

This paper aims to explore underlying resource expenditures during its inference and provide insights in how multimodal LLMs world building exhaust compute in the context of visual novels.

---

## Experimental Setup

Three visual novel world complexities are tested. Each category has worlds generated by an LLM that fills up schematic outputs.

| # | Mode    | Character Sprites | Background Images | Character Dialogues |
|---|---------|:-----------------:|:-----------------:|:-------------------:|
| 1 | Static  | 5                 | 3                 | 5                   |
| 2 | Static  | 15                | 5                 | 15                  |
| 3 | Dynamic | 15                | 5                 | 15                  |

### Modes

**Static**
- Linear dialogues
- Single state tracking: character sprites, background images, character sprite static expression
- Zero branching choices

**Dynamic**
- Multi-turn dialogues
- Multi state tracking: character sprites, background images, character sprite dynamic expression
- Branching choices
